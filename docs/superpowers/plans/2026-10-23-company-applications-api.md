# Интеграция компаний, заявок, документов и финансов

**Цель:** перевести доступные клиентские операции с demo-моков на актуальный backend из `origin/main`, сохранив мок только для отсутствующих серверных сценариев.

## Границы

- Backend не изменяем.
- Ничего не пушим до ручной проверки.
- Компании, ядро заявок, загрузка PDF и финансовые записи работают через API.
- Поиск нового ИНН временно использует demo-реестр после серверного `404`: backend ищет только в локальной БД.
- Распознавание PDF, удаление PDF, скоринг, предложения и кабинет банка остаются demo-моками: соответствующих ручек нет.
- ФИО берём из `/auth/me`. Должность сохраняем локально: backend пока её не отдаёт и не принимает.

## Задачи

1. Добавить Vitest и контрактные тесты преобразований данных и `multipart/form-data`.
2. Исправить HTTP-клиент: не задавать `Content-Type` для `FormData`.
3. Подключить `GET/POST /companies`, поиск по ИНН и маппинг полей компании.
4. Связать новую заявку с `company_id`; убрать скрытое продолжение после ошибки submit.
5. Подключить загрузку и чтение документов заявки.
6. Подключить `GET/PUT/confirm` финансов; конвертировать рубли в копейки и обратно.
7. Обновить мастер: сохранить и подтвердить финансы перед переходом к проверке.
8. Запустить БД, миграции, backend и frontend. Выполнить API-smoke и ручную проверку браузером.
